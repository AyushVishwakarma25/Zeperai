
ZEPERAI STUDIO - PRODUCT FLOW & UX ARCHITECTURE

================================================================================
1. USER JOURNEY MAPS
================================================================================

FLOW A: THE "SMART" CREATIVE START (Brand-First Approach)
1.  **Onboarding:** User Logs in.
2.  **Brand Identity Setup (Critical):** 
    -   User opens "Brand Identity" from sidebar.
    -   Uploads Logo.
    -   AI analyzes Logo -> Auto-fills Primary Colors, Fonts, and Tone of Voice.
    -   User saves Brand Kit. (This now applies to ALL future generations).
3.  **Creation:** User goes to Dashboard, selects "Product Photoshoot".
    -   The system automatically prompts the AI: "Use brand color #6A5AE0 for lighting accents."

FLOW B: THE "DATA-DRIVEN" AD CAMPAIGN (Shopify Integration)
1.  **Ingestion:** User goes to "Shopify Analyzer".
2.  **Upload:** User drops a CSV export of their Monthly Sales.
3.  **Analysis:** System visualizes Revenue Trends and creates "Product Zones".
    -   User sees "Red Zone" (Underperforming Products).
4.  **Action:** User clicks "Create Clearance Ad" on a Red Zone product.
5.  **Generation:** App redirects to "Ad Creative" mode with pre-filled context:
    -   *Objective:* Clearance/Urgency.
    -   *Product Name:* From CSV.
    -   *Ad Copy:* "Last Chance to Buy".

FLOW C: THE CONTENT ENGINE (Generation -> Copy -> Deploy)
1.  **Visual:** User generates a batch of 4 images in "Fashion Studio" mode.
2.  **Selection:** User picks the best shot.
3.  **Writing:** Opens "AI Content Writer" in the detail panel.
    -   Selects Platform: "Instagram".
    -   AI generates Caption + Hashtags based on the image visual context.
4.  **Persistence:** User clicks "Save". Image is uploaded to Cloud Storage; Data saved to DB.
5.  **Analytics:** User views "Brand Analytics" to see predicted CTR scores for the asset.

================================================================================
3. INTERACTION STATES
================================================================================

LOADING STATES
- **Spinner Overlay:** "Generating... (2/4)" with a progress bar for batch operations.
- **Micro-copy:** "Warming up the AI models...", "Polishing pixels...".

ERROR STATES
- **Toast Notifications:** "Insufficient Credits", "Upload Failed", "Network Error".
- **Fallback UI:** If offline, the AI buttons disable and show "Offline Mode".

SUCCESS STATES
- **Gallery View:** Results appear immediately in a Masonry grid.
- **Confetti:** On first successful generation of the session.
